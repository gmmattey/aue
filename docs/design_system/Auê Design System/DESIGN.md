# Auê!

> Category: Brands

> Surface: web

*Arrote. Seja julgado.*

PWA mobile-first de competição de arrotos — jogo social competitivo, irreverente e visualmente premium apesar do caráter absurdo do produto. Referências: Wavelength, BeReal, Kahoot, Duolingo, Strava.

## Color Palette

| Role | Name | Hex | Usage |
| --- | --- | --- | --- |
| background | Preto Carvão | `#0a0a08` | fundo de tela, quase preto |
| surface | Superfície Elevada | `#171712` | superfícies discretamente elevadas, usadas com moderação — evitar transformar todo agrupamento em card |
| foreground | Texto Claro | `#f5f3ea` | texto principal sobre fundo escuro |
| muted | Texto Secundário | `#93917f` | labels, metadados, instruções secundárias |
| border | Borda | `#2b2a22` | divisores sutis, raramente visíveis |
| accent | Verde Ácido Elétrico | `#c6ff00` | cor primária de destaque — CTA principal (ARROTAR), Auê Score, elementos vivos. Evitar tom de verde hospitalar/vômito. |

## Typography
- **Display:** Anton — weights 400 — fallbacks: Archivo Black, Impact, system-ui, sans-serif
- **Body:** Inter — weights 400, 600, 700 — fallbacks: system-ui, -apple-system, Segoe UI, Helvetica Neue, Arial, sans-serif

## Voice & Tone

- **Adjectives:** irreverente, competitivo, espontâneo, debochado, direto, engraçado
- **Tone:** Jogo social competitivo, não rede social/utilitário/app corporativo. Irreverência e humor pontual (resultado, derrota, conquista, erro, compartilhamento, competição) sem virar piada em todo label. Microcopy curta, direta, sem texto técnico — ex.: 'MANDA.', 'JULGANDO ESSA PORRA...', 'A dignidade também.'

### Messaging pillars
- irreverência
- competição
- espontaneidade
- suspense
- recompensa
- compartilhamento

### Vocabulary
- **Use:** ARROTAR, Auê Score, DESAFIAR, REVANCHE, JULGANDO..., MANDA., Campeonato, Pódio
- **Avoid:** jargão técnico (ex: 'baseline RMS'), linguagem de app corporativo/dashboard, onboarding longo/explicativo, piada em todo label

## Imagery

- **Style:** Contemporâneo, energético, propositalmente exagerado — party game premium + cultura digital + streetwear + esporte absurdo
- **Subjects:** Bolha Auê (elemento orgânico animado, assinatura visual central, não perfeitamente circular), score em grande destaque, pódio / ranking
- **Treatment:** Baixa densidade visual, tipografia grande, um elemento visual dominante por tela, motion com significado (nunca só decorativo)
- **Avoid:** waveform tradicional como elemento principal, excesso de cards, aparência de app corporativo/dashboard, dependência exclusiva de emojis para personalidade

## Layout

- **Radius:** 24px (amplamente arredondado)
- **Border weight:** 1px, uso discreto
- **Spacing:** grid 8px; baixa densidade — grandes áreas vazias, poucas métricas simultâneas, informação progressiva

### Posture rules
- Uma ação principal por tela, hierarquia evidente
- Tema escuro obrigatório: fundo quase preto, superfícies discretamente elevadas, textos claros
- Auê Score deve sempre ter protagonismo (25–40% da atenção visual na tela de resultado)
- Métricas em linhas com barra de progresso, não em cards independentes
- Botão primário grande e alto contraste; evitar três CTAs igualmente chamativos
- Navegação principal: Ranking / ARROTAR (destaque central) / Perfil — sem tabs extras
- Mobile-first, viewport 360–430px, uma mão; desktop centralizado, ~480–600px
- Suporte a prefers-reduced-motion mantendo a informação completa
