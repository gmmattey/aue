Instalação

03

Cole no <head>. São seis linhas: navegadores modernos usam o SVG, os antigos caem no ICO, o iOS usa o apple-touch-icon e o Android lê tudo pelo manifest. Não use <link rel="apple-touch-icon-precomposed"> — está obsoleto desde o iOS 7.

<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/assets/favicon/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/assets/favicon/apple-touch-icon.png">
<link rel="mask-icon" href="/assets/favicon/safari-pinned-tab.svg" color="#c6ff00">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#0a0a08">

O site.webmanifest já declara os cinco ícones, display: standalone, orientação retrato e as duas cores de sistema. theme_color e background_color são ambos --bg: a splash screen do Android nasce da mesma cor de fundo do app, sem emenda visível na abertura.

// site.webmanifest — trecho
"background_color": "#0a0a08",
"theme_color":      "#0a0a08",
"display":          "standalone",
"orientation":      "portrait",
"icons": [
  { "src": "…/android-chrome-192.png", "sizes": "192x192", "purpose": "any" },
  { "src": "…/android-chrome-512.png", "sizes": "512x512", "purpose": "any" },
  { "src": "…/maskable-192.png",       "sizes": "192x192", "purpose": "maskable" },
  { "src": "…/maskable-512.png",       "sizes": "512x512", "purpose": "maskable" }
]

Um achado sobre o símbolo

04

A haste e o pingo do ! se tocam

No símbolo registrado a haste desce até y=137 e o pingo começa em y=134. Os dois se fundem: o ! fica sem vão. A ~180px isso ainda lê como um ponto de exclamação de pingo colado; a 16px vira uma mancha escura dentro de um anel verde — e some justamente o elemento que, segundo a seção 12 do design system, existe para tirar a ambiguidade de "blob genérico de startup".

Nos rasters de 48px para baixo apliquei correção óptica — haste mais grossa e pingo deslocado para baixo — porque um favicon ilegível é um favicon quebrado. De 180px para cima o conjunto é fiel ao símbolo, sem retoque: mexer na marca é decisão sua, não minha.

A correção definitiva é no próprio aue-bolha-mark.svg — abrir ~10 unidades de vão. Feito isso, um python system/scripts/build-favicons.py regenera o conjunto inteiro já consistente entre tamanhos.
