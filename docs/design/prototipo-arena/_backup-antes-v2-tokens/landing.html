Auê!

O Auê! é feito pra celular.

Arrote. Seja julgado. É um app instalável — funciona melhor direto no seu bolso, com microfone e notificações de verdade. Instale no celular pra jogar.

aue.app

Copie o link e abra no navegador do seu celular pra instalar.

Não apareceu o prompt de instalação?

No Chrome / Edge: clique no ícone de instalar (⊕) na barra de endereço.

No Safari (iPhone): toque em Compartilhar → Adicionar à Tela de Início.

No Chrome (Android): menu ⋮ → Instalar app.
